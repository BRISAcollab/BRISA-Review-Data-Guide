# BRISA Review Data Guide

A simple static website for the BRISA systematic review data organization guide.

## Files

- `index.html` — site content
- `styles.css` — layout and visual design
- BRISA logo — loaded from the official BRISA website

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save.

No build step or external framework is required.
